# QAVRA

**Qavra is an academic social platform for students in Azerbaijan.** It brings AI-powered exam preparation, personalized opportunity discovery and a student community together in one app.

- 🌐 **Website:** [qavra.app](https://qavra.app)
- 📱 **Android:** [Astrava Studios on Google Play](https://play.google.com/store/apps/dev?id=5428945462490019066)

## What Qavra does

- **Exam preparation:** Upload question files and lecture notes (PDF, DOC, DOCX, TXT). Qavra turns them into interactive, AI-generated practice tests.
- **Performance analytics:** Tracks results and highlights weak areas so revision can focus on them.
- **Academic feed:** A shared feed for academic updates and announcements.
- **Student community:** University community groups and direct messaging between students.
- **Student housing:** Housing and rental listings for students.
